# Rule 6: Image Licensing

- Never copy images from Blinkit, Zepto, BigBasket, Amazon, Google Images or any app/site without a licence that allows it.
- Every catalog image must have its source URL, author and licence recorded in `docs/catalog_image_sources.csv` and the master catalog workbook.
- CC BY / CC BY-SA images must be listed in `docs/IMAGE_CREDITS.md` and credited in the app. Prefer CC0 / public domain.
- No identifiable people in catalog images. Visually check automatic matches before use.
- Store images as small WebP (<=400px) in `assets/catalog-images/`, named by item ID (e.g. `DG0001.webp`).
